# Project Tracker (PyQt6)
A simple Python + PyQt6 desktop app for tracking time spent on multiple projects. The app provides a main window for managing projects and a compact mini‑window for quick start/stop logging.

## Features
- Track time per project with a 1‑second timer
- Add new projects through the UI
- Auto‑save project data to data.json
- Mini floating window for quick logging
- UI built with Qt Designer (.ui files)
